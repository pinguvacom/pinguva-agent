# Pinguva Agent Source 0.2.16

Этот каталог содержит исходный код агента Pinguva версии 0.2.16.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.

## Что добавлено в 0.2.16

- автоматический поиск активных access-log по стандартным путям и конфигурации Nginx/Apache;
- сохранение HTTP-метода и пользовательского пути журнала для маршрута;
- режим `ANY` для URL без указанного метода;
- отправка только агрегированных счётчиков без исходных строк журнала.
