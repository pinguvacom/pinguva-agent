# Pinguva Agent Source 0.2.21

Этот каталог содержит исходный код агента Pinguva версии 0.2.21.

Версия 0.2.21 поддерживает последовательные многострочные JSON-объекты с полями
`time`, `method`, `url`, `httpCode`, `totalTime` в локальном журнале исходящих
API-запросов. Поддерживаются файлы `request.json` и `sms.json` в каталоге
`/ilab/monitoring/`; фактический `requestUrl` не отправляется. Файлы должны
оставаться недоступными через веб-сервер.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.
