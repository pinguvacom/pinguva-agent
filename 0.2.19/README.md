# Pinguva Agent Source 0.2.19

Этот каталог содержит исходный код агента Pinguva версии 0.2.19.

Версия 0.2.19 локально распознаёт стандартные access-log, JSONL и
многострочные PHP/cURL-журналы приложения для мониторинга выбранных API-маршрутов.
В Pinguva отправляются только агрегаты запросов, ошибок и задержек.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.
