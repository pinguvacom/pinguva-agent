# Pinguva Agent Source 0.2.15

Этот каталог содержит исходный код агента Pinguva версии 0.2.15.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.

## Что добавлено в 0.2.15

- сохранение HTTP-метода и пользовательского пути access-log для маршрута;
- режим `ANY` для URL без указанного метода;
- чтение безопасных application log paths и отправка только агрегатов;
- совместимость с таблицами Excel в формате `Название`, `URL`, `Метод`, `Путь к логу`.
