# Pinguva Agent Source 0.2.14

Этот каталог содержит исходный код Pinguva Agent версии `0.2.14`.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.

## Что добавлено в 0.2.14

- мониторинг бизнес-API по стандартным access-log Nginx и Apache;
- получение списка наблюдаемых маршрутов через обычный ответ `/api/agent/report`;
- отправка только минутных агрегатов по выбранным маршрутам;
- маскирование источников трафика;
- нормализация динамических частей пути в `:value`.

## Что не передаётся

- тела запросов и ответов;
- HTTP-заголовки;
- cookies;
- query string;
- токены;
- сырые access-log;
- персональные данные;
- исходный SQL и параметры запросов.
