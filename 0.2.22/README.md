# Pinguva Agent Source 0.2.22

Этот каталог содержит исходный код агента Pinguva версии 0.2.22.

Версия 0.2.22 позволяет привязать к выбранному Linux-серверу источник
исходящих API-запросов: URL используется только как подсказка для локального
пути, а не для HTTP-загрузки. Агент читает ограниченный хвост локального
JSON-журнала, находит безопасные `name`, `method` и шаблоны `url` и предлагает
маршруты для выбора в Pinguva. В отчёт не попадают фактический `requestUrl`,
сырые строки журнала и тела запросов. Отмеченные маршруты агрегируются по
минутам; существующий ручной мониторинг access-log сохраняется.

Закройте публичный HTTP-доступ к журналу приложения до подключения источника.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.
