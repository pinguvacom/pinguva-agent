# Pinguva Agent Source 0.2.17

Этот каталог содержит исходный код агента Pinguva версии 0.2.17.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.

## Что добавлено в 0.2.17

- поддержка access-log, где код ответа расположен перед HTTP-запросом;
- чтение длительности из блока даты вида `+0500 - 0.146`;
- сохранение агрегированных счётчиков без передачи исходных строк журнала.
