# Pinguva Agent Source 0.2.20

Этот каталог содержит исходный код агента Pinguva версии 0.2.20.

Версия 0.2.20 сообщает состояние журнала для каждого настроенного маршрута API:
файл не найден, нет доступа, формат не распознан или журнал доступен. Ошибка
одного файла не скрывается доступным access-log и не блокирует сбор по другим
маршрутам. Содержимое журналов не передаётся.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.
