# Pinguva Agent Source 0.2.23

Этот каталог содержит исходный код агента Pinguva версии 0.2.23.

Для выбранных маршрутов бизнес-API агент считает HTTP-коды ошибок по минутам.
Передаются только код и количество, без URL фактического запроса, его параметров
или содержимого журнала. Новые поля опциональны для старого backend.

Агент не принимает входящие подключения, работает только через исходящий HTTPS,
не выполняет удалённые команды и не отправляет содержимое конфигурационных файлов.
Это можно проверить по исходникам в этом каталоге.
